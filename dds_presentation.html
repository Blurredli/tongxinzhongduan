🎯 项目背景

为什么选择DDS？

信号发生器是电子测试测量领域最基础的仪器之一，广泛应用于通信系统、电子测试、教学实验等领域。


传统模拟信号发生器存在频率稳定性差、调节精度低、波形种类有限等缺点。

❌ 传统模拟方案

频率稳定性差、精度低、波形单一

✅ DDS数字方案

高分辨率、快切换、相位连续、灵活可调

🎯 设计目标

  • 🔧

    基于Zynq-7010 SoC平台

    ARM+FPGA异构架构，充分发挥SoC优势

  • 📊

    支持三种波形输出

    正弦波、方波、三角波，满足不同应用需求

  • ⚡

    32位相位累加器

    频率分辨率0.0233Hz，远优于0.1Hz要求

  • 🎮

    双重控制方式

    本地按键控制 + 远程UART串口控制

  • 📈

    8位DAC输出

    0-255幅值范围，支持模拟信号输出

📚 DDS核心原理

fout = (FCW × fclk) / 2N

fout = 输出频率 | FCW = 频率控制字 | fclk = 系统时钟(100MHz) | N = 累加器位宽(32)

🔄 相位累加器

工作原理

32位寄存器，每个时钟周期累加FCW值。当累加值超过2³²时自然溢出，形成周期性相位变化。


高8位[31:24]作为波形查找表地址，实现相位到幅值的映射。

// 相位累加器 Verilog 实现
always @(posedge clk or negedge rst_n) begin
  if(!rst_n)
    phase_acc <= 32'd0;
  else
    phase_acc <= phase_acc + fcw;
end

🎮 按键控制模块

功能特性

  • ⬆️

    Freq+ (key[0])

    频率增加1kHz

  • ⬇️

    Freq- (key[1])

    频率减少1kHz

  • 🔄

    Wave (key[2])

    波形切换：SIN→SQU→TRI

消抖原理

采用延时消抖方式，消抖时间10ms（1,000,000个时钟周期@100MHz）。


当按键状态稳定保持10ms以上才确认为有效按键，避免机械抖动造成的误触发。


parameter FCW_STEP = 32'd107374;
// 约对应1kHz频率步进

📡 UART通信模块

接收指令格式

// 格式: 'F' + 6位ASCII数字
F001000 → 1 kHz
F010000 → 10 kHz
F100000 → 100 kHz
F200000 → 200 kHz
F999999 → 999.999 kHz

发送回显格式

// 格式: 波形 + 频率BCD
SIN000100 → 正弦波 1kHz
SQU000100 → 方波 1kHz
TRI000100 → 三角波 1kHz
