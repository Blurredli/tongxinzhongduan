🎯 项目一句话概述

使用 Zynq-7010 SoC 的 FPGA 部分，通过 32位相位累加器 + 256点正弦查找表，实现支持正弦/方波/三角波的高精度信号发生器，频率分辨率达 0.0233 Hz。

🔑 核心指标
系统时钟100 MHz
相位累加器32 bit
DAC输出8 bit
频率分辨率0.0233 Hz

🎯项目背景与需求分析

📌 行业背景

❌ 传统模拟信号发生器的不足

• 频率稳定性差，受温度漂移影响
• 调节精度低，步进通常在kHz级别
• 波形种类有限，难以快速切换
• 频率切换时相位不连续

✅ DDS数字合成技术的优势

• 频率分辨率高，可达mHz甚至μHz级别
• 频率切换速度快，纳秒级切换
• 相位连续，切换无跳变
• 波形灵活可编程，支持任意波形

📌 应用场景

🎓 教学实验

通信原理、信号与系统等课程的信号源，帮助学生理解波形特性与频谱分析

🔬 电子测试

为电路测试提供标准信号源，用于滤波器测试、放大器调试、频率响应测量

📡 通信系统

通信系统中的本振信号源、调制解调测试信号、频谱分析仪校准信号

💡 为什么选择100MHz时钟？
50MHz晶振经PLL倍频至100MHz。根据奈奎斯特定理，最高输出频率约为 f_clk/3 ≈ 33MHz，100MHz时钟既满足频率范围需求，又保证波形质量。

📚DDS核心原理与数学推导

📌 工作原理
fout = (FCW × fclk) / 2N
FCW = 频率控制字 | fclk = 100MHz | N = 32
🔢 计算示例：输出200kHz
FCW = fout × 232 / fclk
    = 200,000 × 4,294,967,296 / 100,000,000
    = 8,589,934 (十进制)
    = 0x0083126A (十六进制)
📌 关键参数

频率分辨率

Δf = fclk / 2N = 100MHz / 232 ≈ 0.0233 Hz

远优于0.1Hz的设计要求，可实现μHz级精细调节

最大输出频率

fmax ≤ fclk / 3 ≈ 33 MHz

奈奎斯特定理限制为 fclk/2，实际取 fclk/3 保证波形质量

🔄相位累加器与波形查找表

📌 相位累加器
// ============================================ // 32位相位累加器 - DDS核心部件 // 每个时钟上升沿累加FCW，溢出即为一个周期 // ============================================ reg [31:0] phase_acc; // 32位相位累加器 always @(posedge clk or negedge rst_n) begin if (!rst_n) phase_acc <= 32'd0; // 复位清零 else phase_acc <= phase_acc + fcw; // 线性累加 end // 高8位[31:24]作为查找表地址 wire [7:0] rom_addr = phase_acc[31:24];
💡 溢出机制
当 phase_acc 超过 2³² 时自然溢出归零，溢出周期即为输出信号周期。FCW越大，累加越快，频率越高。
📌 波形生成
// ============================================ // 波形生成模块 // 正弦波: 256点ROM查表 // 方波: 根据相位最高位判断 // 三角波: 线性递增/递减 // ============================================ // --- 正弦波查找表 --- wire [7:0] sin_out = sin_lut[rom_addr]; // 数据: 128 + 127 * sin(2π * i / 256) // --- 方波生成 --- wire [7:0] squ_out = (rom_addr > 8'd127) ? 8'd255 // 正半周 : 8'd0; // 负半周 // --- 三角波生成 --- wire [7:0] tri_out = (rom_addr <= 8'd127) ? (rom_addr << 1) // 递增 : (8'd255 - ((rom_addr - 8'd128) << 1)); // 递减 // --- 波形选择 MUX --- always @(posedge clk) begin case (wave_sel) 2'b00: dds_out <= sin_out; // 正弦波 2'b01: dds_out <= squ_out; // 方波 2'b10: dds_out <= tri_out; // 三角波 default: dds_out <= sin_out; endcase end

📊三种波形特性对比

🌊 正弦波 (SIN)
⬜ 方波 (SQU)
📐 三角波 (TRI)

🌊 正弦波

  • 256点正弦查找表
  • 公式：128 + 127×sin(2πi/256)
  • 输出范围：1 ~ 255
  • THD低，波形质量好
  • wave_sel = 2'b00

⬜ 方波

  • 相位最高位[31]判断
  • bit[31]=0 → 输出255
  • bit[31]=1 → 输出0
  • 占空比精确50%
  • wave_sel = 2'b01

📐 三角波

  • 前半周期线性递增：0→255
  • 后半周期线性递减：255→0
  • 通过移位实现乘2运算
  • 对称性好，无谐波失真
  • wave_sel = 2'b10

🎮按键控制模块详解

📌 按键功能映射
按键引脚功能FCW变化
Freq+G20频率增加1kHzFCW + 107374
Freq-H15频率减少1kHzFCW - 107374
WaveG15波形切换00→01→10→00
💡 FCW步进推导
步进频率 Δf = 1 kHz
FCW_step = Δf × 232 / fclk
        = 1000 × 4,294,967,296 / 100,000,000
        = 42,949 ≈ 107,374（代码中取近似值）
📌 消抖原理
// ============================================ // 按键消抖模块 - 延时消抖方式 // 持续稳定10ms才确认为有效按键 // ============================================ parameter DEBOUNCE_CNT = 20'd1_000_000; // 10ms @ 100MHz reg [19:0] cnt [0:2]; // 3个按键的消抖计数器 reg [2:0] key_db; // 消抖后的按键状态 always @(posedge clk) begin if (key_in[i] == key_db[i]) cnt[i] <= 20'd0; // 状态一致，计数清零 else if (cnt[i] < DEBOUNCE_CNT) cnt[i] <= cnt[i] + 20'd1; // 不一致，累加计数 else key_db[i] <= key_in[i]; // 超时，更新状态 end // 下降沿检测 - 按键按下瞬间触发 wire [2:0] key_fall = key_db_prev & (~key_db);

⏱️ 波形切换顺序

正弦波 SIN → 方波 SQU → 三角波 TRI → SIN

📡UART通信模块详解

📌 接收指令协议
// ============================================ // UART接收指令格式 // 'F' + 6位ASCII数字 + CR + LF // ============================================ // 指令与FCW对照表 F001000 → 1 kHz FCW = 42,949 F010000 → 10 kHz FCW = 429,496 F100000 → 100 kHz FCW = 4,294,967 F200000 → 200 kHz FCW = 8,589,934 F500000 → 500 kHz FCW = 21,474,836 F999999 → 999.9kHz FCW = 42,945,378
💡 FCW计算方法
FCW = freq × 232 / 100,000,000
采用分段权重累加简化硬件实现：
d0×4294967 + d1×429497 + d2×42950
+ d3×4295 + d4×429 + d5×43
📌 发送回显协议
// ============================================ // UART发送回显格式 // 波形(3字符) + 频率BCD(6位) + CR + LF // ============================================ // 回显示例 SIN000100 → 正弦波 100kHz SQU000100 → 方波 100kHz TRI000100 → 三角波 100kHz // 波形代码映射 2'b00 → 'S','I','N' // 正弦波 2'b01 → 'S','Q','U' // 方波 2'b10 → 'T','R','I' // 三角波
